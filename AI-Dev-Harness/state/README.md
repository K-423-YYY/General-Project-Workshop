# state（项目归档区）

本目录由 AI 自动维护，**不进项目**，用于保存每个项目的历史，实现「下次修改自动恢复」。

每个项目一个子目录，例如：
```
state\
└── <项目名>\
    ├── harness\        ← 上次清理前归档的 .harness\ 工作文件（计划、架构、检查点、状态）
    ├── status.json     ← 项目状态标记（completed / in-progress）
    └── ...
```

- 开工时：AI 从这里恢复上次的计划与记忆；
- 完成清理时：AI 把项目 `.harness\` 归档到这里，再删除项目内脚手架；
- 这样项目文件夹始终纯净，而历史不会丢。

> 本目录内容为内部状态，用户一般不需要手动修改。
