# 项目模板说明

本目录存放**项目骨架模板**，AI 在阶段 1/2 会参考这里的模板生成 `方案.md`、`需求与理念.md` 等项目文档。

- `方案模板.md`、`需求与理念模板.md`：阶段 2 生成两份项目文档时使用。
- `gitignore.template`：通用 .gitignore 模板。
- `plan-checklist.md`、`prompt.md`：来自通用技能的辅助模板。

你可以直接编辑这些模板，AI 下次生成时就会采用你的新版。

**已有方案文档时**：这两份模板是「从零设计」时用的；用户手上已有方案 / 计划文档时，
AI 应把已有内容**归并**成项目里的 `方案.md` 与 `需求与理念.md`（以原文为基准补全体例），
不要另起一份与原文矛盾的方案 —— 见 `自定义\对话协议.md` 第 2–3 章。

**边界（铁律 · `AGENTS.md` 第五节）**：本目录属于「可改区」，你可以随便改模板；
但 `AI-Dev-Harness\自定义\对话协议.md`、`规则源.md`、两个能力表、`scripts\`、`bin\`、`引擎适配\`、`prompt-模板\`，
以及工作区根的 `.claude\` 与 `日志\` 属**机制层（框架资产）**，项目开发期间不得改动（`日志\` 只追加）。
要改，先确认「这是修 harness，不是做项目」。
