# Exception Handling

## 适用场景
步骤 7：出现异常、失败、不可行、需要用户决策时。

## 必须遵守规则
1. 异常发生时先停止当前部分执行。
2. 向用户报告：当前进度、具体问题、已尝试方案、可选方案、需要用户做什么。
3. 等待用户决定。
4. 办不到或重复几轮仍办不到时，移交用户手动执行，并说明怎么执行。

## 执行步骤
1. 判断触发条件：
   - 模板方案失败；
   - 计划不可行；
   - 网络/凭据/权限不足；
   - 计划与需求冲突。
2. 停止当前部分执行。
3. 输出异常报告。
4. 等待用户决定。
5. 用户决定后按决定继续。

## 验证方式
- 用户已收到完整异常报告。
- 用户已做出决定。
- 后续执行按用户决定进行。

## 问题与解决方案
| 问题 | 第一方案 | 是否需要手动 |
|---|---|---|
| 模板方案失败 | 提示用户 | 是 |
| 计划不可行 | 停止并询问用户 | 是 |
| 网络/凭据不足 | 提示用户手动执行 | 是 |
| 重复多轮仍失败 | 移交用户手动执行 | 是 |

## 禁止行为
- 禁止隐瞒异常。
- 禁止替用户做方向性决定。
- 禁止在用户未决定前继续有争议部分。

## 成功判定
- 异常已报告。
- 用户已决定。
- 后续按用户决定执行。
