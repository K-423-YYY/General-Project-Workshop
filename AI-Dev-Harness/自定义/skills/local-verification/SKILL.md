# Local Verification

## 适用场景
步骤 5：项目骨架搭建完成后的验证。

## 必须遵守规则
1. 验证通过才能进入下一步。
2. 验证失败先按模板第一方案处理。
3. 处理失败后提示用户并询问。

## 执行步骤
1. 语法检查：
   ```powershell
   bash -n 脚本.sh
   ```
2. PowerShell 脚本语法检查。
3. 编码检查：.ps1 统一 UTF-8 BOM，中文不乱码。
4. 冒烟测试：用假执行器跑通生成、执行、完成、修改等路径。
5. 真实连通测试：用真实 CLI 做最小调用，确认模型、API、网络可用。
6. 运行 selftest 类脚本确认可重复运行。

## 验证方式
- 所有脚本语法通过。
- 冒烟测试全部通过。
- 真实连通测试通过。
- 自测通过。

## 问题与解决方案
| 问题 | 第一方案 | 备用方案 | 是否需要手动 |
|---|---|---|---|
| 中文乱码 | 统一 UTF-8 BOM | 转换编码 | 否 |
| 语法错误 | 按错误信息修复 | 询问用户 | 否 |
| 真实环境不可用 | 提示用户 | 用户手动验证 | 是 |

## 禁止行为
- 禁止跳过验证直接进入下一步。
- 禁止忽略失败结果。
- 禁止把未验证内容当作已完成。

## 成功判定
- 全部验证通过。
- 验证记录已输出。
