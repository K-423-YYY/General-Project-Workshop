# Cleanup and Final

## 适用场景
步骤 10-12：项目收尾。

## 必须遵守规则
1. 只删除临时文件，不删除计划内文件。
2. 清理后必须再次检查目录和 git 状态。
3. 最终交付必须经用户确认。

## 执行步骤
1. 删除运行状态目录：.codex-run/。
2. 删除临时测试目录和日志文件。
3. 删除任务提示文件 prompt.md（如不再需要）。
4. 检查根目录：
   ```powershell
   Get-ChildItem -Force
   git status
   ```
5. 输出最终说明：项目地址、提交 SHA、项目结构、使用方式、自动化脚本用法、后续维护命令。
6. 请用户确认远程内容和交付结果。

## 验证方式
- 目录中无临时文件。
- git 状态干净。
- 用户确认完成。

## 问题与解决方案
| 问题 | 第一方案 | 是否需要手动 |
|---|---|---|
| 不确定文件是否多余 | 先询问用户 | 是 |
| 用户未确认交付 | 等待用户确认 | 是 |

## 禁止行为
- 禁止删除计划内文件。
- 禁止在用户未确认时宣布完成。
- 禁止留下临时文件。

## 成功判定
- 项目目录干净。
- git 状态干净。
- 交付说明已输出。
- 用户已确认。
