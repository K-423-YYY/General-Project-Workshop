# Skeleton Building

## 适用场景
步骤 4：创建项目结构。

## 必须遵守规则
1. 只创建计划书要求的目录和文件。
2. 不添加计划外内容。
3. 完成后列出新增文件清单。

## 执行步骤
1. 读取任务拆分表。
2. 创建计划内目录和文件。
3. 包括入口脚本、验证脚本、技能规范、说明文档、示例文件、配置文件。
4. 列出新增文件清单供核对。

## 验证方式
- 新增文件均能在计划书找到依据。
- 无计划外文件。
- 目录结构符合计划。

## 问题与解决方案
| 问题 | 第一方案 | 是否需要手动 |
|---|---|---|
| 计划未定义结构 | 停止并询问用户 | 是 |
| 结构不合理 | 提示用户后按决定执行 | 是 |
| 文件冲突 | 停止并询问用户 | 是 |

## 禁止行为
- 禁止创建计划外目录。
- 禁止删除计划内目录。
- 禁止自行决定技术方向。

## 成功判定
- 项目骨架已创建。
- 新增文件清单已确认。
