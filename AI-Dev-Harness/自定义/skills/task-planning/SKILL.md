# Task Planning

## 适用场景
步骤 3：执行前任务梳理。

## 必须遵守规则
1. 任务必须来自计划书，不自行新增。
2. 每个任务必须有独立验收标准。
3. 任务过大时拆分为可单轮完成的小任务。
4. 与计划书逐项比对，发现缺失、冲突、不可行时提示用户。

## 执行步骤
1. 从计划书中提取任务清单。
2. 为每个任务填写：编号、目标、优先级、验收标准、是否单轮可完成、依赖关系。
3. 将任务清单与计划书逐项比对。
4. 输出任务拆分表。
5. 如有问题，停止并询问用户。

## 验证方式
- 每个任务都有编号和验收标准。
- 所有任务都能从计划书找到依据。
- 无计划外任务。

## 问题与解决方案
| 问题 | 第一方案 | 是否需要手动 |
|---|---|---|
| 计划缺失任务 | 停止并询问用户 | 是 |
| 任务冲突 | 停止并询问用户 | 是 |
| 任务不可行 | 停止并询问用户 | 是 |
| 任务过大 | 拆分为子任务 | 否 |

## 禁止行为
- 禁止添加计划外任务。
- 禁止删除计划内任务。
- 禁止替用户决定方向。

## 成功判定
- 任务拆分表完整。
- 与计划书一致。
- 用户确认任务清单。
