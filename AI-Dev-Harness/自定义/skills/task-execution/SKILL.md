# Task Execution

## 适用场景
步骤 6：执行主任务。

## 必须遵守规则
1. 严格按计划书执行。
2. 不擅自扩大范围、改变实现方式。
3. 发现需要偏离计划时，先停下询问用户。
4. 长任务中断时优先恢复，不重头开始。
5. **改代码只用 Edit / Write 工具**（见下方「改码方式」）。
6. **按 L1/L2/L3 分层跑测试**（见下方「测试分层」）。

## 改码方式（硬规则，违反即返工）
- **禁止** `sed -i`、`perl -i`、`cat > 源文件`、`python`/`perl` 内联改码。
- **原因**：内联替换在 Windows 下会**静默失配**——退出码 0、命令看起来成功，文件却根本没改（或改错位置）。
  上次事故里因此改坏代码 4 次而 AI 完全不知道。
- **正确做法**：改代码用 Edit / Write 工具；批量机械改写也用 Edit 逐处改，或先在 STATUS.md 写明提案征得用户同意。
- 命令被机制层拦下时，**照它给的替代方案做，不要换种写法绕过**。
- 需要一次性例外时，建 `.harness/bypass` 文件临时放行，**用完立即删除**。

## 测试分层（禁止「改一行 → 跑全量」）
| 层 | 触发时机 | 跑什么 | 配额 |
|---|---|---|---|
| **L1** | 改完一处 | 对应测试文件（秒级） | 不限 |
| **L2** | 任务边界 | 全量单测 + 类型检查（+ lint） | 不限 |
| **L3** | 阶段收尾 | 全量 E2E | **2 次 / 会话，失败不计数** |
- 失败先看 stderr / 日志再改，禁止「猜 → 改 → 重跑」。
- 详细分层与禁止矩阵见 skill `local-verification`。

## 上下文与成本纪律
- **分层加载**：只读当前任务相关文件，不通读整库；`node_modules` / `dist` / `.git` 一律不读不 grep。
- **拒绝全量代码库输入**，**严禁全量载入项目不相关的代码历史**。
- 长输出命令重定向到文件，只读回**失败项 + 末尾**。
- 探索类任务（「找找哪里用到了 X」）交给子代理，不要把整库读进主上下文。
- 状态与进度用 **append 追加**，不要重写整篇状态文档。
- 连续 2 轮无进展 → 立即停下汇报，不要盲目重试。
- 上下文用到 70% 就结束会话并写 HANDOFF，不要硬撑到压缩开始丢细节。

## 执行步骤
1. 创建任务提示文件 `prompt.md`，包含不可变目标、可变执行步骤、验收标准。
2. 使用自动化脚本执行：
   ```powershell
   codex-autoresearch --no-full-auto --skip-git-repo-check --no-stream run --prompt-file .\prompt.md --frozen-goals-text "..."
   ```
3. 中断后恢复：
   ```powershell
   codex-autoresearch session resume --last
   ```
4. 每轮检查完成状态。
5. 发现异常或偏离计划时，调用 exception-handling。

## 验证方式
- 计划内任务全部完成。
- 每个任务验收标准满足（跑验证脚本取原始输出，不用自述）。
- 无计划外改动（`git status --short` / `git diff --stat` 自查）。

## 问题与解决方案
| 问题 | 第一方案 | 备用方案 | 是否需要手动 |
|---|---|---|---|
| 长任务中断 | session resume --last | 重新创建任务 | 否 |
| 子进程无网络/凭据 | 停止脚本，提示用户 | 用户手动执行 | 是 |
| 需要偏离计划 | 停止并询问用户 | 等待用户决定 | 是 |
| 改码命令被机制层拦下 | 改用 Edit / Write 工具 | 建 `.harness/bypass` 临时放行 | 否 |
| 命中 L3 配额被拦 | `--need-e2e <理由>` 追加 | 留到阶段收尾再跑 | 否 |

## 禁止行为
- 禁止绕过计划自行发挥。
- 禁止在用户未决定前偏离计划。
- 禁止把失败任务标记为完成。
- 禁止用 `sed -i` / `cat >` / python 内联改码（静默失配）。
- 禁止「改一行 → 跑全量 E2E」。
- 禁止在未读日志的情况下重跑失败命令。
- 禁止为了省钱而跳过该跑的 L1 验证。

## 成功判定
- 计划内任务全部完成。
- 验收标准全部满足。
- 无计划外改动。
