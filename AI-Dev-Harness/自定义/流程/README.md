# 流程（项目开发流程规范）

- `万能项目开发流程模板.md`：完整流程标准模板（步骤、角色、异常处理、验证、停止/手动移交原则）。
- `skills-usage.md`：skills 的修改与新增说明。

> 本目录属于「可改区」，你可以按需调整流程；但流程的总体约束（不擅自改目标/范围、每步验证、异常先问用户）建议保留。

**边界（铁律 · `AGENTS.md` 第五节）**：本目录可以改；但 `AI-Dev-Harness\自定义\对话协议.md`、`规则源.md`、
两个能力表、`scripts\`、`bin\`、`引擎适配\`、`prompt-模板\`，以及工作区根的 `.claude\` 与 `日志\` 属**机制层（框架资产）**，
项目开发期间不得改动（`日志\` 只追加）。要改，先确认「这是修 harness，不是做项目」。

**已有方案文档时**：流程模板第 1 步（读取计划书/需求/理念）优先于「从零聊方案」——
用户手上已有方案 / 计划文档时，先放进项目文件夹，再用 `plan-and-requirements` 只读核对，别重复造方案。
