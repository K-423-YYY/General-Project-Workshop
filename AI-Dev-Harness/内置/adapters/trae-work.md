# TraeWork 桌面版

## 形态
字节独立桌面 Agent（TraeWork），支持文字、语音、附件、技能等输入，可在对话中直接预览成果并验收。

## 规则加载
- TraeWork 支持「规则」（固定硬约束）与「技能」（封装流程）分离管理。
- 打开/接入本工作区时，请把 `AI-Dev-Harness\开始项目.md` 的内容发给 TraeWork，或在规则里导入 `AGENTS.md`。

## 使用步骤
1. 在 TraeWork 中把工作目录指向 本文件夹 根目录（或把 本文件夹 复制到本地后打开）。
2. 粘贴 `AI-Dev-Harness\开始项目.md` 内容，或用中文说明要做的项目。
3. 全程中文对话，按 `自定义\对话协议.md` 完成项目。

## 注意
- TraeWork 以 Agent 方式运行任务，AI 会自己按需执行命令，不使用后台常驻进程。
- 模型与能力以 TraeWork 官方为准。
