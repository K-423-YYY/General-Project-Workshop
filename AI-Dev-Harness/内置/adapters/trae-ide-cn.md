# Trae IDE 国内版

## 形态
Trae IDE（国内版）右侧 AI 对话框。内置国产模型（豆包 / DeepSeek / Qwen / Kimi / GLM 等）。

## 规则自动加载
- Trae 的项目规则放在 `项目根\.trae\rules\`。
- 打开 本文件夹 根目录时，请粘贴 `AI-Dev-Harness\开始项目.md`，或导入 `AGENTS.md`。
- 进入项目文件夹开发时，阶段生成的 `.trae\rules\project_rules.md` 会自动生效。

## 使用步骤
1. 用 Trae 打开整个文件夹（或它的副本）。
2. 在右侧对话框粘贴 `AI-Dev-Harness\开始项目.md` 的内容，再描述项目。
3. 全程中文对话，按 `自定义\对话协议.md` 完成项目。

## 注意
- 国内版为国产模型，能力与免费额度以官方为准。
- 不使用后台进程。
