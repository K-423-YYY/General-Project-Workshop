# Codex 客户端（桌面对话框）

## 形态
Codex 桌面应用 / Codex CLI 的对话界面，用中文对话。

## 规则自动加载
- 打开 本文件夹 根目录时，Codex 自动读取根目录 `AGENTS.md`（入口规则）。
- 进入项目文件夹开发时，自动读取项目内的 `AGENTS.md`（阶段生成的脚手架规则，指向 `..\AI-Dev-Harness\`）。

## 使用步骤
1. 用 Codex 打开整个文件夹（或它的副本）。
2. 直接说「我想做……」，或粘贴 `AI-Dev-Harness\开始项目.md` 的内容。
3. 之后全程中文对话，按 `自定义\对话协议.md` 完成项目。

## 注意
- 本项目为可复制工作区：所有路径都是相对路径，Codex 的工作目录即为 本文件夹 根目录。
- 不使用后台进程；AI 自己按需运行命令。
