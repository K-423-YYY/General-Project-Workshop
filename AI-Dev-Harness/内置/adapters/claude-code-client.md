# Claude Code 客户端（桌面客户端对话框）

## 形态
Claude Code 桌面客户端 / 在 VS Code 等 IDE 中的 Claude Code 对话界面。

## 规则自动加载
- 打开 本文件夹 根目录时，Claude Code 读取根目录 `CLAUDE.md` 或 `AGENTS.md`（本工作区已提供 `AGENTS.md`，Claude Code 新版同样读取）。
- 进入项目文件夹开发时，读取项目内的 `CLAUDE.md` / `AGENTS.md`。

## 使用步骤
1. 用 Claude Code 打开整个文件夹（或它的副本）。
2. 说「我想做……」，或粘贴 `AI-Dev-Harness\开始项目.md` 的内容。
3. 全程中文对话，按 `自定义\对话协议.md` 完成项目。

## 注意
- 若打开的是项目文件夹而非 本文件夹 根目录，请先粘贴 `AI-Dev-Harness\开始项目.md`。
- 不使用后台进程。
