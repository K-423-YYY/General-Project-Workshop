# 使用说明（一页看懂）

## 这个文件夹是什么
一个**可整体复制的通用 AI 项目开发配置包**。把它和 `我的项目` 文件夹一起放进任意目录，复制整个文件夹，交给任意 AI，就能用中文对话完成一个完整项目。

## 怎么用（三步）
1. **复制**：把整个文件夹复制到你想做项目的地方（换电脑、换目录都行）。
2. **交给 AI**：用 Codex / Claude Code / DeepSeek Harness / Trae 打开这个文件夹；
   - 若 AI 没自动读到规则，就把 `AI-Dev-Harness\开始项目.md` 的内容粘贴进对话框。
3. **中文对话**：AI 会先跑一次开工体检，再问你「想做什么项目？」，然后按 `自定义\对话协议.md` 一步步带你完成：方案 → 文档 → 命名 → 开发 → 清理 → GitHub。

> **已经有一份方案/计划文档？** 把它放进项目文件夹（`我的项目\`，或改名后的项目目录）里的任意位置，
> 开工时直接说一句「我已经有方案文档，在 xxx，请按它来做，不要再从零设计方案」——
> AI 会用 `plan-and-requirements` 先只读核对一遍，再把内容归并成项目里的 `方案.md` 与 `需求与理念.md`（见 `自定义\对话协议.md` 第 1–3 章）。

## 目录结构
```
本文件夹\
├── AGENTS.md              ← 入口规则（打开即自动生效）
├── README.md              ← 一页看懂 + 完整流程
├── .claude\               ← 机制层：hooks + settings.json（开发期生效，不进交付物）
├── 日志\                  ← 日志中心：8 个分类子目录（只追加、不进 git）
├── 项目说明\              ← 需求理念 / 目录架构 / 使用说明（3 份文档）
├── AI-Dev-Harness\
│   ├── 开始项目.md         ← 手动粘贴入口
│   ├── 使用说明.md         ← 本文件
│   ├── 自定义\             ← ★可改区：流程 / skills / templates / 项目规则模板
│   │   └── （对话协议、规则源、两个能力表、scripts、bin、引擎适配、prompt-模板 = 机制层，别改）
│   ├── 内置\               ← 不用改：8 个软件适配 / 脚本 / 终端引擎 / 历史设计文档
│   └── state\              ← 各项目归档（自动维护，不进项目）
└── 我的项目\              ← 项目文件夹（做项目时会被改名）
```

## 你要改东西去哪改
- 想改流程：`自定义\对话协议.md`
- 想加技能：把含 `SKILL.md` 的文件夹复制进 `自定义\skills\`（即插即用；冲突会自动问你怎么处理）
- 想改项目模板：`自定义\templates\`
- 想改各软件的规则模板：`自定义\项目规则模板\`
- 想改硬规则/铁律：改 `自定义\规则源.md`，再跑 `node AI-Dev-Harness\自定义\scripts\gen-rules.mjs`（会自动同步到 5 处消费方）

> 其余不要动：`.claude\`、`自定义\bin\`、`自定义\scripts\`、`自定义\规则源.md`、`自定义\模型能力表.json`、
> `自定义\引擎能力表.json`、`自定义\引擎适配\`、`自定义\prompt-模板\` 与 `内置\` 属**机制层/内置区**（框架资产）。
> 确实要改，先确认「这是修 harness，不是做项目」（铁律见 `AGENTS.md` 第五节）。

## 承诺与铁律（完整版见 `AGENTS.md` 第五节）
1. **可复制**：所有路径都是相对路径，复制到任何电脑、任何用户名下都能用。
2. **无后台**：不用时不运行任何进程、不建定时任务、不开机自启；脚本只在任务需要时按需运行，收尾自动关闭所有进程。
3. **只说话不敲命令**：全程中文对话，终端/脚本操作由 AI 完成（唯一例外：GitHub 同步命令由你自己执行）。
4. **纯净交付**：项目完成后先给你「将删除 / 将保留」清单，你确认才清理，清完还要跑纯净度自检（`AI-Dev-Harness\自定义\scripts\purity-check.mjs`）。
5. **GitHub 只告知**：AI 只输出可复制的步骤与命令，不代替你推送（你说「你帮我推」才代做）。

## 终端模式（可选，不常用）
想用终端自动跑，运行 `AI-Dev-Harness\内置\engine\run.bat "项目目标"`：
它会先列出可用引擎（回车沿用上次选择），启动时打印「本次引擎 + 机制层是否生效」，再注入启动词。
详情见 `内置\adapters\` 各软件说明。平时用对话框即可。
