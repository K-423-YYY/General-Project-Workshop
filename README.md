\# General‑Project‑Workshop



\## 项目简介

本仓库用于存放项目文档、方案资料、操作笔记，记录项目完整过程。



\## 运行/使用环境

\- 操作系统： Windows



\## 仓库说明

1\. 所有版本使用 Git 进行版本管理，每次提交会记录改动内容

2\. 本地修改完成后执行 `git add .` → `git commit -m "改动说明"` → `git push` 同步到远程 GitHub

3\. 如需在另一台电脑使用，使用 `git clone 仓库地址` 下载完整项目



\## 常用命令备忘

```powershell

\# 查看改动状态

git status



\# 提交全部改动

git add .

git commit -m "填写本次修改说明"

git push



\# 拉取远程最新到本地

git pull



\# 下载仓库到新电脑

git clone https://github.com/K-423-YYY/General-Project-Workshop.git



\# 查看历史提交记录

git log
