# General-Project-Workshop（通用项目坊）

一个**可整体复制、可交给任意 AI 的通用项目开发工作区**：把整个文件夹复制到任何电脑，交给 Codex / Claude Code / DeepSeek Harness / Trae 等任意 AI，就能用**中文对话**完成一个完整、纯净的项目。

你不需要写代码、不需要敲命令——只负责用中文说想法、做决定，其余由 AI 完成。

---

## 一、它能做什么

- 用中文对话完成从「想法」到「交付」的完整项目：需求 → 方案 → 文档 → 命名 → 开发 → 验证 → 清理 → GitHub。
- 适配 4 个软件、8 种形态：Codex 客户端；Claude Code 客户端/终端；DeepSeek Harness（客户端/终端）；Trae IDE 国内版/国际版；TraeWork 桌面版；TraeCode CLI。
- 项目完成后自动清理脚手架，只留下纯净的项目文件（代码 + 文档 + git 记录）。
- 所有可改的配置（流程、技能、模板）集中在一个「可改区」，你可以随时修改，不影响内置部分。

## 二、核心特性

| 特性 | 说明 |
|---|---|
| 中文对话 | 全程中文，不用命令，不限定某一套 AI |
| 即插即用 | 复制文件夹 → 交给 AI → 开工 |
| 通用 | 任意项目类型：网页 / 桌面 / 脚本 / 文档 / 自动化 |
| 纯净交付 | 脚手架开发期存在，完成后自动清除，下次自动再生 |
| 可定制 | 「可改区」（自定义）与「内置区」（适配/脚本）物理隔离 |
| 技能库 | skills 即插即用，并带冲突自动检测 |
| 可复制 | 全相对路径，复制到任何电脑 / 用户名都能用 |
| 无后台 | 不用时不运行任何进程，无定时任务 / 自启 / 文件监听 |

│   ├── 自定义\              ← ★可改区：你随便改

│   │   ├── 流程\            ← 万能项目开发流程模板
│   │   ├── skills\          ← 即插即用技能库（23 个技能）
│   │   ├── templates\       ← 项目文档模板
│   │   └── 项目规则模板\    ← 生成项目脚手架的规则模板

│   │   ├── adapters\        ← 8 个软件适配说明

## 五、快速上手（三步）

1. **复制**：把整个文件夹复制到你想做项目的地方（换电脑、换目录、换用户名都行）。
2. **交给 AI**：用 Codex / Claude Code / DeepSeek Harness / Trae 打开这个文件夹；如果 AI 没自动读到规则，就把 `AI-Dev-Harness\开始项目.md` 的内容粘贴进对话框。
3. **中文对话**：AI 会先问你「想做什么项目？」，然后按流程一步步带你完成整个项目。

## 六、完整使用流程

### 阶段 0 · 开工
AI 用中文问候，问你「想做什么项目？」，并复述确认你的需求，不急着动手。

### 阶段 1 · 方案沟通与确认
AI 通过一步步对话把项目聊清楚（做什么、主要功能、技术偏好、是否发布等），整理成「方案清单草稿」给你看；你可以反复修改，直到说「确认 / 可以生成方案」。

### 阶段 2 · 文档生成
确认后，AI 在项目文件夹生成两份文档并永久保留：
- `方案.md`：整个项目的方案（目标、功能、技术方案、实施步骤、验收标准）
- `需求与理念.md`：需求清单与设计理念

### 阶段 3 · 项目命名
AI 推荐 3–5 个名字供你选择，或由你自己起名；确定后把「我的项目」文件夹改名为项目名，并写入两份文档。

### 阶段 4 · 执行与交付
- **开发**：按方案搭建骨架、逐个功能开发，每步最小验证，git 提交进度。
- **结束与清理**：全部完成并验证通过后，AI 先问你「满意吗？是否同意结束？」，同意后才归档工作文件、删除脚手架、提交纯净版。
- **同步 GitHub**：清理完成后才问你是否同步，索要仓库地址等信息后推送。
- **异常处理**：卡住 / 循环 / 不可行时立即停止，说明原因并给方案，反复「执行 → 停止 → 修改」直到完成。
- **验收与终止**：验收通过并同意停止后，关闭本次开启的所有进程并交付。

## 七、纯净化生命周期

```
开工 → 生成脚手架（按软件最少化）→ 开发 → 完成
   → 用户确认清理 → 归档到 state\ → 删除脚手架 → 提交纯净版
   → 下次修改：自动恢复 → 重新生成脚手架 → 改完再清
```

## 八、技能机制

- **即插即用**：把含 `SKILL.md` 的文件夹复制进 `自定义\skills\` 即可用，无需登记。
- **冲突检测**：新增技能时自动体检（同名 / 职责重叠 / 规则冲突 / 调用顺序冲突），通过中文对话问你怎么处理：删除 / 优化使其兼容 / 保留两者。

## 九、个性化定制

- 想改流程 → 编辑 `AI-Dev-Harness\自定义\对话协议.md`
- 想加技能 → 复制进 `AI-Dev-Harness\自定义\skills\`
- 想改模板 → `AI-Dev-Harness\自定义\templates\`、`自定义\项目规则模板\`
- 内置区 `AI-Dev-Harness\内置\` 不需要改

## 十、终端模式（可选）

平时推荐用客户端对话框；想用终端自动跑：

```powershell
.\AI-Dev-Harness\内置\engine\run.bat "你的项目目标"
```

详情见 `AI-Dev-Harness\内置\adapters\` 各软件说明。

## 十一、使用前提

- 操作系统：Windows（脚本为 PowerShell）；Linux/macOS 可运行 `run.sh`。
- 至少安装一个支持软件：Codex / Claude Code / DeepSeek Harness / Trae。
- 无需额外配置、无需后台服务。
